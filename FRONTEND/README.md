# To-do-list
 This is a React.js frontend application for the To-Do List system.

## Features
-> Add new tasks
-> View all tasks
-> Mark tasks as completed
-> Delete tasks
-> Real-time UI updates

## Endpoints
GET /todos
POST /todos
PUT /todos/{id}
DELETE /todos/{id}

## Commands
npm create vite@latest FRONTEND
npm install
npm install -D tailwindcss
npx tailwindcss init -p
npm install react-router-dom axios
npm run dev
